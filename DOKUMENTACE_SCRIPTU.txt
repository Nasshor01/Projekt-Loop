1. PŘEHLED STRUKTURY PROJEKTU
================================================================================

Projekt je roguelike karetní hra postavená v Godot 4. Hlavní složky:
- data/     - Datové třídy (Resource) pro karty, artefakty, jednotky, atd.
- scenes/   - Scénové skripty pro UI a herní logiku
- scripts/  - Pomocné skripty (autoload, AI, map, resources, debug)

================================================================================
2. DATA SKRIPTY (data/)
================================================================================

2.1 TERRAIN (data/terrain/)
---------------------------
TerrainData.gd
- Popis: Definuje vlastnosti terénu na bojišti
- Třída: Resource
- Klíčové vlastnosti:
  * terrain_id, terrain_name, description, sprite
  * is_flat_on_ground (bool) - zda leží na zemi nebo stojí
  * is_walkable, blocks_line_of_sight, movement_cost
  * effect_type (enum) - typ efektu terénu
  * effect_string_value, effect_numeric_value, effect_duration
- Použití: BattleGrid používá pro umístění terénu na mřížku
- Navazuje na: BattleGrid.gd, Unit.gd (process_terrain_effects)

2.2 ARTIFACTS (data/artifacts/)
--------------------------------
ArtifactsData.gd
- Popis: Hlavní datová třída pro artefakty
- Třída: Resource
- Klíčové vlastnosti:
  * artifact_name, description, texture, artifact_type (enum)
  * trigger_type (enum) - kdy se efekt spouští (PASSIVE, START_OF_TURN, atd.)
  * effect_type (enum) - typ efektu (MODIFY_MAX_HP, GAIN_BLOCK, atd.)
  * primary_value, secondary_value, percentage_based
  * uses_per_combat, current_uses - limity použití
  * is_stackable, max_stacks, current_stacks - stohování
  * synergy_set_id - pro synergii s jinými artefakty
  * condition_type, condition_value - podmíněné efekty
  * custom_effect_id - pro custom efekty
- Klíčové funkce:
  * can_trigger() -> bool - zkontroluje, jestli se může aktivovat
  * use_artifact() - označí jako použitý
  * reset_for_new_combat() - resetuje pro nový souboj
  * add_stack() -> bool - přidá stack
  * get_effective_value() -> int - vrátí efektivní hodnotu s ohledem na stacky
  * check_condition(context) -> bool - zkontroluje podmínku
  * get_formatted_description() -> String - popis s aktuálními hodnotami
  * get_rarity_color() -> Color - barva podle vzácnosti
- Navazuje na: ArtifactManager.gd, ArtifactEffect.gd, PlayerData.gd

ArtifactEffect.gd
- Popis: Wrapper třída pro vykonání efektu artefaktu
- Třída: RefCounted
- Klíčové funkce:
  * execute() -> bool - vykoná efekt artefaktu
  * _apply_effect() -> bool - aplikuje konkrétní efekt podle typu
  * _apply_custom_effect() -> bool - aplikuje custom efekty
- Navazuje na: ArtifactsData.gd, ArtifactManager.gd

ArtifactPool.gd
- Popis: Kontejner pro pole artefaktů
- Třída: Resource
- Vlastnosti: artifacts: Array[ArtifactsData]
- Použití: Pool soubory (.tres) pro různé typy artefaktů

2.3 ENCOUNTERS (data/encounters/)
----------------------------------
EncounterData.gd
- Popis: Definuje souboj s nepřáteli
- Třída: Resource
- Vlastnosti:
  * encounter_type (enum: NORMAL, ELITE, BOSS)
  * xp_reward (int)
  * enemies: Array[EncounterEntry]
- Navazuje na: BattleScene.gd, GameManager.gd

EncounterEntry.gd
- Popis: Definuje jednu jednotku v souboji a její pozici
- Třída: Resource
- Vlastnosti:
  * unit_data: UnitData
  * grid_position: Vector2i
- Navazuje na: EncounterData.gd

2.4 UNITS (data/units/)
-----------------------
UnitData.gd
- Popis: Datová třída pro jednotky (hráč i nepřátelé)
- Třída: Resource
- Vlastnosti:
  * unit_id, unit_name, description
  * faction (enum: PLAYER, ENEMY, NEUTRAL)
  * max_health, attack_damage, movement_range, attack_range
  * initiative (int) - pro tahový systém
  * sprite_texture: Texture2D
  * ai_script: Script - skript AI pro nepřátele
- Navazuje na: Unit.gd, BattleScene.gd, AI skripty

2.5 CARDS (data/cards/)
-----------------------
CardData.gd
- Popis: Hlavní datová třída pro karty
- Třída: Resource
- Vlastnosti:
  * card_id, card_name, card_description
  * cost (int) - cena zahrání
  * range_type (enum) - typ dosahu
  * range_value (int) - hodnota dosahu
  * tags: Array[CardTag] - tagy karty (ATTACK, SPELL, atd.)
  * rarity (enum: COMMON, UNCOMMON, RARE, EPIC, LEGENDARY, BASIC)
  * required_class: ClassData, required_subclass: SubclassData
  * artwork: Texture2D
  * effects: Array[CardEffectData] - efekty karty
  * is_upgraded (bool), upgraded_version: CardData
- Klíčové funkce:
  * add_effect(effect: CardEffectData)
  * has_tag(tag_to_check: CardTag) -> bool
  * can_be_used_by(player_class, player_subclass) -> bool
- Navazuje na: CardEffectData.gd, BattleScene.gd, PlayerData.gd

CardEffectData.gd
- Popis: Definuje jeden efekt karty
- Třída: Resource
- Vlastnosti:
  * effect_type (enum) - typ efektu (DEAL_DAMAGE, GAIN_BLOCK, atd.)
  * value (int) - číselná hodnota
  * string_value (String) - textová hodnota
  * target_type (enum) - cíl efektu (SELF_UNIT, SELECTED_ENEMY_UNIT, atd.)
  * area_of_effect_type (enum) - typ AoE (SINGLE_TARGET, ROW, COLUMN, atd.)
  * aoe_param_x, aoe_param_y (int) - parametry AoE
- Navazuje na: CardData.gd, BattleScene.gd (_apply_single_effect)

CardPool.gd
- Popis: Kontejner pro pole karet
- Třída: Resource
- Vlastnosti: cards: Array[CardData]
- Použití: Pool soubory pro různé typy karet

StartingDeckPool.gd
- Popis: Pool pro startovní karty
- Třída: Resource
- Vlastnosti:
  * attack_cards: Array[CardData]
  * defend_cards: Array[CardData]
  * utility_cards: Array[CardData]
- Navazuje na: SubclassData.gd

2.6 CLASSES (data/classes/)
---------------------------
ClassData.gd
- Popis: Definuje hlavní třídu postavy
- Třída: Resource
- Vlastnosti:
  * class_id, display_name, description
  * base_unit_data: UnitData
- Navazuje na: SubclassData.gd, PlayerData.gd

SubclassData.gd
- Popis: Definuje podtřídu postavy
- Třída: Resource
- Vlastnosti:
  * subclass_id, subclass_name, description
  * parent_class: ClassData
  * starting_deck: Array[DeckEntry]
  * specific_unit_data: UnitData
  * passive_skill_tree: PassiveSkillTreeData
- Navazuje na: ClassData.gd, PlayerData.gd, PassiveSkillTreeData.gd

2.7 SKILLS (data/skills/)
-------------------------
PassiveSkillTreeData.gd
- Popis: Datová třída pro strom pasivních dovedností
- Třída: Resource
- Vlastnosti:
  * skill_nodes: Array[PassiveSkillNode]
  * nodes_by_id: Dictionary (runtime cache)
- Klíčové funkce:
  * _build_lookup_dictionary() - vytvoří cache uzlů podle ID
  * get_node_by_id(id) -> PassiveSkillNode
- Navazuje na: PassiveSkillNode.gd, PassiveSkillTree.gd

PassiveSkillNode.gd
- Popis: Definuje jeden uzel ve stromu dovedností
- Třída: Resource
- Vlastnosti:
  * id: StringName, skill_name, description
  * icon: Texture2D, position: Vector2
  * tier (enum: TIER_1 až TIER_5)
  * node_type (enum: BASIC, NOTABLE, KEYSTONE, MASTERY, STARTER)
  * cost (int), connected_nodes: PackedStringArray
  * prerequisite_nodes: PackedStringArray
  * effects: Array[PassiveEffectData]
  * is_starter (bool), max_allocations (int)
  * branch (String), branch_position (int)
  * unlock_conditions: Array[String]
  * is_unlocked (bool) - runtime stav
  * allocation_count (int) - runtime stav
- Klíčové funkce:
  * get_node_size() -> float - velikost podle typu
  * get_node_color() -> Color - barva podle typu a stavu
  * get_cost_for_tier() -> int - náklady podle tieru
  * can_allocate() -> bool - zda lze alokovat
  * get_formatted_description() -> String
- Navazuje na: PassiveEffectData.gd, PassiveSkillTreeData.gd

PassiveEffectData.gd
- Popis: Definuje efekt pasivní dovednosti
- Třída: Resource
- Vlastnosti:
  * effect_type (enum) - typ efektu (ADD_MAX_HP, CRITICAL_CHANCE_BONUS, atd.)
  * value (int) - hodnota efektu
  * string_value (String)
  * secondary_value (int)
  * conditional (bool), condition_description (String)
- Klíčové funkce:
  * get_formatted_description() -> String
- Navazuje na: PassiveSkillNode.gd, PlayerData.gd (apply_passive_skills)

SkillTreeGenerator.gd
- Popis: Generátor stromu dovedností pro Paladina
- Třída: RefCounted
- Klíčové funkce:
  * generate_paladin_tree() -> PassiveSkillTreeData - generuje celý strom
  * create_node(...) -> PassiveSkillNode - vytvoří uzel
  * add_effect(node, effect_type, value) - přidá efekt k uzlu
  * setup_connections(nodes) - nastaví propojení mezi uzly
  * auto_position_nodes(nodes) - automaticky pozicuje uzly
  * get_branch_x_offset(branch_name) -> float
  * get_tier_y_offset(tier) -> float
- Navazuje na: PassiveSkillTreeData.gd, PassiveSkillNode.gd

3.1 BATTLE (scenes/battle/)
---------------------------
BattleScene.gd
- Popis: Hlavní scéna pro souboje
- Třída: Node3D
- Klíčové vlastnosti:
  * encounter_data: EncounterData
  * camera_3d: Camera3D
  * battle_grid_instance: BattleGrid
  * _player_unit_node: Unit, _enemy_units: Array[Unit]
  * _current_battle_state (enum: SETUP, AWAITING_PLAYER_SPAWN, PLAYER_TURN, atd.)
  * _player_action_state (enum: IDLE, CARD_SELECTED, UNIT_SELECTED)
- Klíčové funkce:
  * _ready() - inicializace, připojení signálů
  * _process(delta) - pohyb kamery, raycast pro hover
  * _unhandled_input(event) - klikání, zoom kamery
  * start_player_spawn_selection() - výběr spawn pozice
  * confirm_player_spawn(at_position) - potvrzení spawnu
  * spawn_player_unit_at(grid_pos) - spawn hráče
  * spawn_enemy_units() - spawn nepřátel
  * _on_round_started(round_number) - callback z TurnManager
  * _on_turn_started(unit) - callback z TurnManager
  * _start_player_initiative_turn() - zahájí tah hráče
  * _start_enemy_initiative_turn() - zahájí tah nepřítele
  * _process_single_enemy_action() - zpracuje akci nepřítele
  * try_play_card(card, initial_target) - zahrání karty
  * _apply_single_effect(effect, target) - aplikuje efekt karty
  * _get_targets_for_effect(effect, initial_target) -> Array
  * _execute_move(unit, target_cell) - pohyb jednotky
  * get_grid_cell_under_mouse() -> Vector2i - 3D raycast
  * set_enemy_intents() - zobrazí záměry nepřátel
  * _on_unit_died(unit_node) - zpracuje smrt jednotky
- Signály: připojeno na TurnManager, PlayerData, ArtifactManager
- Navazuje na: BattleGrid.gd, Unit.gd, TurnManager.gd, PlayerData.gd, ArtifactManager.gd, AI skripty

BattleGrid.gd
- Popis: Správce mřížky bojiště (3D)
- Třída: Node3D
- Klíčové vlastnosti:
  * cell_size_3d (float) - velikost buňky ve 3D
  * grid_columns, grid_rows (int)
  * _active_cells: Dictionary - aktivní buňky
  * _grid_objects: Dictionary - objekty na mřížce
  * terrain_layer: Dictionary - terén na buňkách
  * _movable_cells, _targetable_cells, _aoe_cells, _danger_cells - highlighty
- Klíčové funkce:
  * build_from_shape(shape_array) - vytvoří mřížku z tvaru
  * place_object_on_cell(object, grid_pos, is_moving) -> bool
  * remove_object_by_instance(object)
  * get_object_on_cell(grid_pos) -> Node
  * get_distance(cell_a, cell_b) -> int
  * is_cell_active(grid_pos) -> bool
  * show_movable_range(unit) - zobrazí pohyblivé buňky
  * show_targetable_cells(cells, is_attack) - zobrazí cílitelné buňky
  * show_aoe_highlight(cells) - zobrazí AoE
  * show_danger_zone(enemy_units) - zobrazí nebezpečnou zónu
  * get_cells_for_aoe(origin, aoe_type, param_x, param_y) -> Array
  * place_terrain(grid_pos, terrain_data)
  * get_terrain_on_cell(grid_pos) -> TerrainData
  * get_player_spawn_points(num_columns) -> Array
  * get_line(from_cell, to_cell) -> Array - Bresenham line
- Navazuje na: BattleScene.gd, Unit.gd, TerrainData.gd

Unit.gd
- Popis: Reprezentace jednotky na bojišti (3D)
- Třída: Node3D
- Klíčové vlastnosti:
  * unit_data: UnitData
  * current_health, current_block, retained_block (int)
  * grid_position: Vector2i
  * active_statuses: Dictionary - aktivní statusy
  * has_used_base_move, extra_moves - pohyb
  * _has_acted_this_turn - akce
  * last_attacker: Unit
  * is_aiming, berserker_frustration, is_permanently_enraged - AI specifické
- Signály: died(unit_node), unit_selected(unit_node), stats_changed(unit_node)
- Klíčové funkce:
  * _ready() - inicializace podle faction
  * attack(target, damage_multiplier) - útok
  * take_damage(amount) - přijme poškození
  * heal(amount) - léčení
  * add_block(amount) - přidá blok
  * apply_status(status_id, value, duration) - aplikuje status
  * process_terrain_effects(terrain_data) - zpracuje terén
  * reset_for_new_turn() - reset pro nový tah
  * start_turn() -> int - začátek tahu, vrací extra_draw
  * end_turn() - konec tahu
  * can_move() -> bool, use_move_action(), gain_extra_move()
  * process_turn_start_statuses() -> int - zpracuje statusy na začátku tahu
  * process_turn_end_statuses() - zpracuje statusy na konci tahu
  * get_current_movement_range() -> int
  * show_intent(attack_damage), hide_intent()
  * _show_floating_text(amount, type) - zobrazí floating text
- Navazuje na: UnitData.gd, BattleScene.gd, BattleGrid.gd, PlayerData.gd, ArtifactManager.gd

CameraMovement.gd
- Popis: Ovládání 2D kamery (používá se na mapě)
- Třída: Camera2D
- Klíčové funkce:
  * set_camera_limits(grid_width, grid_height, cell_size)
  * _unhandled_input(event) - pohyb a zoom myší
- Navazuje na: Map.gd

6.1 KRITICKÉ CHYBY
------------------
1. EventManager.gd - CHYBÍ PUBLIC FUNKCE
   Soubor: scripts/autoload/EventManager.gd
   Problém: Funkce _filter_events_for_floor() a _debug_available_events() jsou
            private (začínají _), ale EventScene.gd je volá jako public.
   Řešení: Přidat public wrapper funkce:
           func filter_events_for_floor(events: Array, floor: int) -> Array:
               return _filter_events_for_floor(events, floor)
           
           func debug_available_events(events: Array, floor: int):
               _debug_available_events(events, floor)

2. SaveManager.gd - ŠPATNÉ NÁZVY PROMĚNNÝCH
   Soubor: scripts/autoload/SaveManager.gd, řádky 64-65
   Problém: Používá player_data.health a player_data.max_health, ale PlayerData
            používá current_hp a max_hp.
   Řešení: Změnit na:
           "health": player_data.current_hp,
           "max_health": player_data.max_hp

3. GameManager.gd - ŠPATNÉ NÁZVY PROMĚNNÝCH
   Soubor: scripts/autoload/GameManager.gd, řádky 400-401
   Problém: V load_and_start_saved_run() používá loaded_data.get("health") a
            loaded_data.get("max_health"), ale SaveManager ukládá jako "health"
            a "max_health" místo "current_hp" a "max_hp".
   POZNÁMKA: Toto je konzistentní s SaveManager, ale mělo by se změnit na
            current_hp a max_hp pro konzistenci s PlayerData.
   Řešení: Změnit v SaveManager.gd i GameManager.gd na current_hp a max_hp
