#65 [CLOSED] UX: FULL_BOARD / ALL_ENEMY cards (Divine Judgment) — misleading target flow
URL: https://github.com/Nasshor01/Projekt-Loop/issues/65
Author: Nasshor01 | Labels: bug, early-alpha, polish, playtest | Milestone: Alpha 0.4
Created: 2026-08-14T08:23:29Z | Updated: 2026-08-14T13:33:36Z
------------------------------------------------------------------------
## Summary
Playtest (LeySpot, Druid fight ~31:02): **Divine Judgment** in hand looked playable (energy cost 3, Exhaust keyword) but player could not figure out how to play it — "just there forever."

## Root cause (code)
`divine_judgment.tres`: `range_type = FULL_BOARD`, damage effect `ALL_ENEMY_UNITS`, plus separate `EXHAUST` effect on `SELF_UNIT`.

Play/routing logic only treats `SELECTED_ENEMY_UNIT` as "enemy effect":
- `has_enemy_effect` ignores `ALL_ENEMY_UNITS`
- Card is routed as "self-only" because EXHAUST uses `SELF_UNIT`
- `_show_valid_targets_for_card` highlights **only player cell**, not full board / all enemies
- Requires 2-step: select card → click/drag grid (non-obvious for "nuke all enemies" card)
- Attack-style drag-to-enemy UX fails player expectation (same class of issue as #58)

**Exhaust is NOT the bug** — card should be playable; exhaust applies after successful play.

## Fix direction
- [ ] `FULL_BOARD` / `ALL_ENEMY_UNITS` cards: one-click play or clear "click anywhere" feedback
- [ ] Include `ALL_ENEMY_UNITS` in enemy-effect / auto-play routing
- [ ] `_show_valid_targets_for_card`: highlight all enemies or full board for FULL_BOARD
- [ ] Smoke: Divine Judgment with 3 energy, multiple enemies on board
